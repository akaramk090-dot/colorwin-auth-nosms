# Welcome and first deposit popups

The first authenticated Home visit shows a compact welcome modal with rainbow heading. Confirm immediately opens the first deposit offer modal and loads server eligibility with Retry on errors. Welcome confirmation is remembered per account in this browser. Both modals are at most 290px wide with mobile side gutters. Closing without “No more reminders today” lets the offer appear on the next main tab navigation (Home, Activity, Tournaments, Promotion or Account), without reopening on background auth refreshes. Selecting the checkbox and closing suppresses reminders for this account until the next India calendar day. Activity → Welcome Bonus always provides the same offers as a page, including when reminders are muted. Deposit buttons open the existing deposit page and prefill ₹300, ₹500, ₹1,000 or ₹2,000. The popup Activity button opens that Welcome Bonus page. Scrollable content, focus trapping, an inert background and SVG close button support mobile and keyboard interaction. Logout removes the modal; late responses cannot reopen it after changing route or account. Storage preferences do not authorize financial operations.

Offers now support manual Claim: ₹300→₹28, ₹500→₹58, ₹1,000→₹88, ₹2,000→₹108, ₹5,000→₹288. No automatic credit occurs. Matched users must press Claim in the popup or Activity page. The protected RPC locks per account and atomically writes a unique claim and wallet credit; repeated requests cannot credit twice. Apply supabase/first-deposit-claim.sql after the status setup. The read-only `colorwin_first_deposit_status` RPC checks the earliest approved deposit in `promotion_deposits`, ordered by completion timestamp and ID. Exact equality selects one tier; totals, pending requests and later deposits cannot qualify an unmatched first deposit. The popup opens before loading status rather than disappearing on a network error. Loading disables deposit actions, errors offer Retry, matched accounts show their matched tier and unmatched accounts show why every tier is unavailable. The Activity Welcome Bonus page uses the same server status. `supabase/first-deposit-status.sql` installs the RPC with active-session checks; SQL tests use rollback-only fixtures.

The banner is saved at `dist/assets/web images/colorwin-welcome-banner.png`, generated with the built-in imagegen tool. Final prompt:
